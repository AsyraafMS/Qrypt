# Phase 2 SARIF and CI Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Deliver SARIF export, tested CI, example reports, and a reproducible container build for the v0.1 milestone.

**Architecture:** Convert the existing normalized report without changing JSON or exit codes. GitHub scans the repository root; source paths remain relative to the scan target. Container dependencies and base image are pinned, and the installed CLI runs as a non-root user.

**Tech Stack:** Python 3.12+, Semgrep CE 1.177.0, pytest, JSON Schema, GitHub Actions, Docker.

**Spec:** README.md, Phase 2 roadmap.

## Global Constraints

- Candidates require verification; zero findings does not establish PQC readiness.
- Preserve source privacy, advisory default, enforcement exit 1, incomplete/error exit 2.
- Preserve AGENTS.md and detector behavior. Commit independently verified units.
- Do not publish or change repository visibility. The public demo requires a public repository and remains an external validation item.

## Review Focus

- Escaped spaces, Unicode and URI metacharacters must identify the correct file.
- Incomplete scans must retain evidence and fail; CI must never upload partial scans.
- Clean scans must emit valid SARIF with no readiness claim.
- Output failures must preserve the previous report and source files.
- Non-root containers must scan read-only mounts offline without executing target code.
