# CycloneDX 1.6 schemas

The three JSON Schema files and Apache 2.0 license were retrieved on 2026-10-13
from the official [CycloneDX specification 1.6 branch](https://github.com/CycloneDX/specification/tree/1.6/schema).
The reference schemas are vendored alongside `bom-1.6.schema.json` so pytest
validates exports offline. No scan report is submitted to an external validator.
